# 甲面拍摄 V0.2

在小米13的浏览器打开[拍摄网页](https://ruanxioa.github.io/nail-camera-v02/)，点“开启相机”，点“允许”，对白色拇指按白色圆钮。去相册选照片，点“保存照片和数据”。手机可以独立使用。

[手机测试步骤、兼容性表与验收结论](https://ruanxioa.github.io/nail-camera-v02/check.html)也保存在本项目的 docs/check.html 中。

## 范围与证据

这是独立的 V0.2。旧版项目和拍摄入口分开保留。复查了 V0.1 的预览约束、静态接口、运动门限、布局和存储，复跑了旧版 32 项检查。新版复用重力数学、校准和原片/JSON 原子存储及 ZIP 导出。

V0.2 通过 42 项自动检查和 12 组桌面 Chrome 浏览器流程。桌面 Chrome 自带虚拟摄像头的静态成片为 3840×2160。原始 JPEG、视频帧及非 JPEG 降级另有测试。小米13的 Chrome 和自带浏览器尚待实际设备验收。真机最高分辨率、绝对倾角误差、三种方式的甲缘质量差和真实 EXIF 覆盖率均无本轮实拍数据。

## 数据

每次采集独立编号。本机 ZIP 里有同编号原文件和 JSON，含 SHA-256。JPEG 白名单仅解析与拍摄相关的字段，不解析 GPS、MakerNote 或序列号。原照片的所有字节保留，因此原片本身可能含私人位置。网页不上传文件，不使用第三方脚本。清理站点存储前请导出。两种浏览器的本地相册相互独立。

JSON 中的 photo 保存编码像素、正向显示尺寸及带来源的 EXIF。camera 保存本机镜头代号、所选后摄、请求日志、实际轨道设置和能力。posture 保存请求附近左右/前后角、来源、稳定性、校准与时间窗内的原始事件。timing 记录浏览器时钟与 EXIF 时间，真实曝光姿态与同步误差上界均未知。preview 保存屏幕像素与视频像素变换、原图可见区域、辅助线位置。网页视频帧与原片像素一一对应。静态照片另有成像链，缺乏真实配准时明确标作未知。review 保存手工甲面区域及观察，不改写原片。

## 开发与复核

docs 是纯静态网站，无运行时依赖，无需构建。使用 Node 22 或以上运行 npm test。tests/browser-check.mjs 可选用独立安装的 playwright-core 运行。QA_PLAYWRIGHT 可指定该包 index.mjs 的绝对路径，QA_CHROME 指定本机 Chromium 可执行文件，QA_OUTPUT 可指定仅保存在本机的测试输出目录。测试仅使用生成的图像、合成传感器事件和浏览器虚拟设备。实际系统相机跳转、甲缘清晰度与角度误差需要真机。
